## ローリングホライゾン

- 空間的に直方体に含まれるブロックを削除する
- ランダムウォークというより、良い局所解を見つけることを優先して温度差はつける
- ただ、温度が低くなるとハマるので、必要だったらreheatする

## adaptive-parallel-annealing

ケースによってスコアのスケールが異なり、適切な温度設定が異なる
最適化時間が長い
並列性を活かしたい

## multi-stage optimize

obj1->obj1+obj2->obj1+obj2+obj3 の順で最適化することを考えたい

- RawScore { z1, z2, z3 } を作る
- {obj1|obj2|obj3}-scaleのスケジュールを設定する
  - scaleは0->1にlinearにあげるようにする
  - パラメータとして、globalの最適化時間における{obj2|obj3}-scaleをあげるstart,endを設定できるようにする
  - z1が0になったらobj2-scaleを1にする
- annealing-scoreにはraw-scoreに重みをかけて計算する
- global-cはobj1だけを考慮する
- global-cはz1=0になったら終了する

## 課題:

長時間の最適化で、より良いスコアを出す
-> 試行ごとにばらつきがある
-> 全体的な構造が異なり、最も良い状態を目指せていない
-> 質の良い局所的なreconstructを増やせれば少しずつ改善しそうではある？
-> tardiness blockが多いので、敷き詰め効率が悪い
-> 敷き詰め効率を上げるには？
-> 色々試すしかない？
-> 高い温度からちゃんと色々な峰を探索する

1位になるには？
- 全てのケースで、試行によらず、良い解に向かう必要がある
- どこら辺の配置が良いかはわからないので、幅広く探索する必要がある
- 局所的な改善を繰り返して到達できる場合
  - reconstruct,insertを改善することでOKになる
- 全体的な構造を改善する必要がある場合
  - 全体の解の構造を与える必要がある
    - どのblockを優先するか、どのbayに配置するか
  - ただ、これをヒューリスティックで事前に求めるのは困難そう
